# 图标设计方案(幸存者割草游戏)

> 当前状态:所有美术已回退为**纯色圆形占位**(无贴图依赖,游戏逻辑完整可玩)。
> 本方案定义新图标的规格、格线、每类实体画什么、以及落地方式——**风格由你定,规格是通用的**。

---

## 一、设计目标与原则

1. **俯视角 2D** 统一视角,所有角色顶部朝上或按移动方向朝向,不出现透视。
2. **剪影清晰**:同一屏几十个怪时,靠**轮廓 + 主色**一眼区分,而不是细节。
3. **主色唯一**:玩家 = 亮色(蓝/青),敌人 = 暖色互斥(绿/紫/红),Boss = 高饱和压迫色。颜色是读屏第一信号。
4. **格子对齐**:所有帧严格落同一格线,避免碰撞圈与画面错位。

---

## 二、通用规格(与风格无关)

| 项目 | 规格 |
|---|---|
| 画布格式 | PNG,透明背景(RGBA8) |
| 基准格 | **64×64** 一帧(所有角色/怪同格) |
| 碰撞圆直径 | 见下表,贴图内容应落在碰撞圆内 |
| 朝向约定 | 角色**默认朝上**(或朝右 0°,代码旋转对齐) |
| 动画帧 | 每角色/怪物:Idle(1) / Walk(2~4) / Hurt(1) / Death(1) |
| 命名 | `<实体>_<动作>.png`,如 `slime_idle.png` |
| 过滤 | 像素风 → Nearest;平滑矢量 → Linear(二选一,全局统一) |

### 显示尺寸(1280×720 视口下的实际像素)

| 实体 | 显示尺寸(直径) | 碰撞直径(2r) | 帧大小建议 |
|---|---|---|---|
| 玩家 | ~64px | 28 | 64×64 |
| 史莱姆(杂兵) | ~32px | 32 | 64×64(内容占满 32px) |
| 蝙蝠(快速) | ~26px | 26 | 64×64 |
| 巨魔(精英) | ~64px | 64 | 64×64 |
| Boss | ~128px | 128 | 128×128(或 64×64 放大2倍) |
| 子弹/箭 | ~18px | 8 | 32×32 |
| 经验宝石 | ~16px | — | 32×32 |
| 红药/宝箱 | ~20px | — | 32×32 |

> 规则:**视觉直径 ≈ 碰撞直径 2r**(玩家可略大)。贴图内容画多大,代码 scale 就按内容实际像素回算,保证显示尺寸命中上表——避免出现"画布大内容小"导致的错判(上次坑)。

## 三、按实体逐类设计(画什么)

### 玩家(唯一主角)
- 主色:亮青/蓝,高对比描边。
- 需求:**4 个角色**共用同一套尺寸,靠**配色 + 装饰**区分:
  - 魔法学徒:蓝袍 + 法杖
  - 圣骑士:白金铠甲 + 盾
  - 光明祭司:白袍 + 光环
  - 幽灵刺客:灰黑 + 匕首
- 简易方案:画 1 个通用小人底图,4 色换肤 + 徽记即可。

### 敌人(3 种,暖色互斥)
| 类型 | 造型 | 主色 | 特征 |
|---|---|---|---|
| 史莱姆 | 圆润一坨 | 绿 | 简单、可爱、无四肢 |
| 蝙蝠 | 小三角翅 | 紫 | 翅膀张开、快 |
| 巨魔 | 大块头 | 红 | 体积大、轮廓敦实 |

### Boss(深渊领主)
- 高饱和深紫/黑红,体型最大。
- 特征:多眼/尖角/幽光,一眼反派。
- 建议做个 128×128 单帧(或 64×64 放大),血条在 HUD 顶部,与 Boss 主色呼应。

### 子弹
- 玩家弹:亮黄小锐角/光点(区别于怪)。
- 敌弹(弹幕):粉/红,与玩家弹形成色彩对立。

### 掉落物
- 经验宝石:绿小菱形,微发光。
- 红药:红十字瓶。
- 宝箱:金色宝箱。

### 战斗 HUD / 菜单(UI 另一套,单独提)
- 血条/经验条、武器图标栏、按钮圆角边框 —— 属于 UI 素材,与实体分开规划(本条不展开)。

## 四、落地方式(代码侧)

1. 素材放入 `assets/textures/<风格>/`,单帧 PNG。
2. 在 [scripts/game_manager.gd](scripts/game_manager.gd) 顶部 `TEXTURES` 表填路径:

```gdscript
const TEXTURES := {
    "player": "res://assets/textures/<风格>/player_idle.png",
    "slime":  "res://assets/textures/<风格>/slime_idle.png",
    # ...
}
```

3. 各脚本已有缩放钩子:`enemy.gd`/`boss.gd` 的 `_r / 16.0`、`main.gd` 玩家 `2.0`、`bullet.gd` —— **按新素材内容像素重算 scale**,保证显示尺寸命中第三节的表。
4. `texture_for()` 已自动兜底:缺图或路径不存在 → 圆形占位,逻辑永不因缺图崩溃。
