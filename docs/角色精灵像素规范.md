# 角色精灵像素规范(四个基础角色)

> 用途:后期用 AI 生成新角色时的风格参照与验收标准。范围:**除只因信徒(xiaoheizi)外**的四个可玩角色。
> 地面真相 = `resource/pixel32/char_<id>_{idle,run,hit}.png`;像素级核验工具 = `map_preview/analyze_char_style.py`(输出逐帧包围盒、全表调色板、idle f0 逐行游程、帧差);16× 目视参照 = `map_preview/_char_zoom16.png`(行=角色,列=idle f0 / idle f5 / run f4 / hit f3)。
> 素材来源:Pixel Adventure 套(game_manager.gd 注释:apprentice→Virtual Guy, paladin→Pink Man, priest→Ninja Frog, assassin→Mask Dude)。

## 1. 共用风格 DNA(新角色必须全中)

### 1.1 画布与精灵表格式
- 每帧 **32×32 RGBA**,背景全透明;alpha 只有 0/255 两档,**零抗锯齿**(无半透明过渡像素)。
- 精灵表横排:idle **11 帧**(352×32, 8fps)、run **12 帧**(384×32, 12fps)、hit **7 帧**(224×32, 10fps)。与 `CHAR_FRAMES` 约定一致。

### 1.2 描边
- 外轮廓 **1px、全角色统一 `#211F30`**(深蓝黑,不是纯黑)。
- 大部件分界也用 `#211F30`(兜帽/脸、面具/脸、头带/头顶之间)。
- **内部细节线不用描边色**,用该部件自身最深色:蛙嘴 `#076029`、蓝帽脸板缝/嘴 `#A14744`、面具牙缝 `#843346`。

### 1.3 上色
- **平涂三档赛璐璐**:每种材质 = 基色 + 1 阴影 + 1 高光;无渐变、无抖动、无半透明。
- 光源**右上**:高光多在右上/顶缘(常为 1px 斜带或点),阴影在**左缘与下缘**。
- 单角色 **9~15 色**;取色落在下方共享色族(同饱和度糖果色系),皮肤/手共用同一组肉色。

### 1.4 比例与站姿(idle f0 实测)
- 总高 **24~28px**、总宽 **21~24px**(含手);**脚底贴 y=31**(画布最下行),无地面阴影、无投影。
- Q 版约两头身:头(含帽/面具/羽冠)**14~16px,占全高 55~65%**;躯干 6~8px(y23~27,宽 10~12px);腿 **4px**(y28~31)两短桩,裆缝为 2~7px 宽描边色缺口。
- **手 = 体侧 2~3px 宽肉色凸块**(y25~26),与躯干隔 1px 描边;蛙类无手(臂即体侧)。

### 1.5 动画约定(帧差实测)
- **idle**:11 帧 = **5 个唯一姿势**,持帧模式 `f0 | f1=f2 | f3=f4 | f5=f6=f7=f8 | f9=f10`。呼吸 = 头+躯干整体**上伸 0→+1→+2→+1 px,脚不动**(bbox 顶 y8→7→6→7);伴随手部 1px 摆动。
- **run**:12 帧 = **8 个唯一姿势**(4 对持帧 `f1=f2, f4=f5, f7=f8, f10=f11`),两步一循环:身体上下颠 ±1~4px(腾空帧脚离 y31,bbox 顶上到 y0~5)+ 双腿交替 + 手反相摆 1px。
- **hit**:7 帧 = **f0=f1 纯白 `#FFFFFF` 剪影闪**(整帧单色,无描边)→ f2 过渡 → f3=f5 中压扁(宽+2~3 / 高-3)→ f4 最大压扁(宽+5 / 高-4,如 apprentice w27 h20)→ f6 恢复。**不变色调、只闪白剪影**。

### 1.6 共享色族(Pixel Adventure 套全局调色板)
| 三色组(基/影/亮) | 用途实例 |
|---|---|
| `#6CD9F1` / `#2FACDA` / `#ACF7FA` | 青:蓝帽兜衣、面具客羽冠 |
| `#F89CC0` / `#EA71BD` | 粉:壮汉身体、羽冠粉羽 |
| `#72A11D` / `#28860F` / `#A4CC42`(亮)+`#076029`(深) | 绿:蛙皮/蛙肚/嘴线 |
| `#CC3048` / `#9C1B4D` / `#E44A4A` | 红:蛙头带 |
| `#FBDFB1` / `#F2BC7E` | 浅肉:手、壮汉脸 |
| `#E4C997` / `#CF9E6E` / `#B96E54` / `#A14744` | 棕 tan:脸板/面具条纹四档 |
| `#843346` | 暗栗:面具客面具基色 |
| `#E68D41` | 橙tan影:面具客皮肤阴影 |
| `#D2612F` | 橙:壮汉护目眼圈 |
| `#FFFFFF` / `#D8E1E4` / `#48475B` | 白/白影/灰紫:兜帽、眼白、眉带 |
| `#211F30` | **全角色统一描边** |

## 2. 蓝帽小子 apprentice(Virtual Guy)

**包围盒**:idle x5–26 / y8–31(22×24);run 腾空帧顶 y4;hit 压扁最宽 x3–29。

## 6. 新角色验收清单(AI 生成后逐条对)

1. 32×32/帧、RGBA、alpha 仅 0/255;表格式 idle 11 / run 12 / hit 7。
2. 外描边 1px 且**恰为 `#211F30`**;内部细节线用部件深色而非描边色。
3. 平涂 ≤15 色,每材质基/影/亮三档;光源右上(高光右上、阴影左下)。
4. idle f0:脚底 y=31、总高 24~28、总宽 21~24、头占 ≥55%、手为体侧 2~3px 凸块、腿 4px 两桩。
5. idle 5 唯一姿势(持帧模式同上)、呼吸只伸头身不动脚;run 8 唯一姿势两步循环;hit f0=f1 **纯白剪影**→压扁→恢复。
6. 核验:`python map_preview/analyze_char_style.py <char_id>` 对比包围盒/调色板/帧差;像素级对规格:docs/角色精灵像素全录.md;目视对照 `map_preview/_char_zoom16.png`。
7. 接入:`TEXTURES` 加 3 个键 + `CHAR_FRAMES` 加条目(32,32,fps 8/12/10)+ `CHARACTERS` 加数值表;跑 `--import` 后再冒烟。

## 附录:像素级地面真相(全量指针)

逐帧 RLE / 逐色像素索引见 **docs/角色精灵像素全录.md**(由 `map_preview/dump_char_pixels.py`
自 `resource/pixel32/char_*.png` 逐像素生成,是本规范唯一地面真相;本文件不复制像素表,改素材后重跑生成器即可,不漂移):

- 帧清单:三动画逐帧像素级去重,`fA≡fB` = 两帧完全相同(持帧),四角色全部一致:
  `idle 11→5 唯一姿势(P0=f0, P1=f1≡f2, P2=f3≡f4, P3=f5≡…≡f8, P4=f9≡f10)`
  `run 12→8 唯一姿势(P0..P3 各 2 帧, P4..P7 各 2 帧)`
  `hit 7→5 唯一姿势(P0=f0≡f1 = 纯白剪影闪帧)`
- 站姿逐色像素索引(idle P0):每种颜色 ×像素数 + 全部游程(按行)。
- 每个唯一姿势的逐行 RLE:`y行: [x0-x1]#HEX ...`,idle 5 + run 8 + hit 5 = 每角色 18 块。

按需导出单帧 RLE/包围盒/调色板/帧差:`python map_preview/analyze_char_style.py <char_id>`。
目视对照:16× 放大图 `map_preview/_char_zoom16.png`(行=角色,列=idle f0 / idle f5 / run f4 / hit f3)。
